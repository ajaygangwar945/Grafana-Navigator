1
Option A: MSI Installer (Recommended)
Download and run the official MSI installer wizard which handles paths and services automatically.
# Download installer from grafana.com/grafana/download
# Run the MSI file and follow standard prompts.
2
Option B: Standalone ZIP Package
Extract the package to your preferred location (e.g. C:\grafana). Open PowerShell as Administrator and run the server binary.
# Navigate into extracted Grafana directory
cd C:\grafana

# Run Grafana Server in the foreground
.\bin\grafana-server.exe
3
Configure Environment Variable (Optional)
Add Grafana's bin folder to the System environment variable path for convenience so you can type grafana-server from anywhere.
# Set PATH environment variable via PowerShell (Admin)
[Environment]::SetEnvironmentVariable("Path", $env:Path + ";C:\grafana\bin", "Machine")
Port Conflict Checks (TCP 3000)
If Grafana fails to bind to port 3000, verify which application is blocking it: 
netstat -ano | findstr 3000
1
Add APT Repositories & Import GPG Keys
Configure security keys and fetch the official stable releases list.
sudo apt-get install -y apt-transport-https software-properties-common wget
sudo mkdir -p /etc/apt/keyrings/
wget -q -O - https://apt.grafana.com/gpg.key | gpg --dearmor | sudo tee /etc/apt/keyrings/grafana.gpg > /dev/null
echo "deb [signed-by=/etc/apt/keyrings/grafana.gpg] https://apt.grafana.com stable main" | sudo tee /etc/apt/sources.list.d/grafana.list
2
Install Grafana OSS
Update lists and trigger installation of the latest stable build.
sudo apt-get update
sudo apt-get install grafana
3
Start and Enable Systemd Service
Ensure Grafana starts automatically during system reboot cycles.
sudo systemctl daemon-reload
sudo systemctl start grafana-server
sudo systemctl enable grafana-server
1
Configure YUM / DNF Repo File
Create /etc/yum.repos.d/grafana.repo containing the installation path configs.
cat <<EOF | sudo tee /etc/yum.repos.d/grafana.repo
[grafana]
name=grafana
baseurl=https://rpm.grafana.com
repo_gpgcheck=1
enabled=1
gpgcheck=1
gpgkey=https://rpm.grafana.com/gpg.key
sslverify=1
sslcacert=/etc/pki/tls/certs/ca-bundle.crt
EOF
2
Install and Run
Fetch Grafana from the repositories and trigger the standard systemd service processes.
sudo dnf install grafana -y
sudo systemctl daemon-reload
sudo systemctl start grafana-server
sudo systemctl enable grafana-server
1
Use Homebrew to Install
Run update commands and install via the Homebrew package repository.
brew update
brew install grafana
2
Manage Background Services
Launch Grafana as a system agent background daemon service or run it manually.
# To start grafana and run on system login
brew services start grafana

# Alternately, run manually inside the terminal foreground:
grafana server --config=/opt/homebrew/etc/grafana/grafana.ini
1
Run Container and Expose Ports
Pull the official Enterprise repository image and expose container port 3000 to the local environment.
docker run -d -p 3000:3000 --name=grafana grafana/grafana-enterprise
2
Mount Configs and Databases (Persistent Storage)
Launch Grafana container with local mapping to ensure dashboard state persists across updates.
docker run -d -p 3000:3000 --name=grafana \
  -v grafana-storage:/var/lib/grafana \
  grafana/grafana-enterprise
Windows Production Deep Dive

When running Grafana on Windows servers for production, launching it through terminal windows is unreliable. Register the binary as a background system service to guarantee it runs on host restarts.

Step 1: Install Service via PowerShell
Use the built-in service flag commands within PowerShell (Admin) to register the executable.
# Run in PowerShell (Admin Mode)
cd C:\grafana\bin

# Register service
.\grafana-server.exe --service-install
Step 2: Service Management Actions
Once registered, manage its state using the Windows Service CLI wrappers or Services UI (services.msc).
# Start Grafana Service
Start-Service -Name "Grafana"

# Stop Grafana Service
Stop-Service -Name "Grafana"

# Check execution health state
Get-Service -Name "Grafana"
Windows Uninstall Options
If you ever need to deregister the service, run: .\grafana-server.exe --service-uninstall from your installation path directory.
CLI & Daemon Commands
grafana-cli plugins list-remote Plugins
Query and retrieve lists of all officially available cloud plugins.
grafana-cli plugins list-remote
grafana-cli plugins install [plugin-id] Plugins
Download and install a plugin directly from repository archives.
grafana-cli plugins install grafana-piechart-panel
grafana-cli plugins update-all Plugins
Update all installed plugins to their latest versions.
grafana-cli plugins update-all
grafana-cli plugins remove [plugin-id] Plugins
Deregister and remove a plugin from the local environment folders.
grafana-cli plugins remove grafana-piechart-panel
grafana-cli admin reset-admin-password [pwd] Administration
Reset the password for the primary admin user if credentials are lost.
grafana-cli admin reset-admin-password newSecurePassword123
sudo systemctl restart grafana-server Daemon Management
Restart the system service daemon on Debian/RedHat based Linux engines.
sudo systemctl restart grafana-server
